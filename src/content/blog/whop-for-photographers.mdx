For a photographer, a shoot is only part of what the client buys. Editing, file delivery, revisions, and image usage can matter just as much. Whop may help collect payment and provide a client space, but the offer needs to explain those deliverables before the client reaches checkout.

## Build the package around the final use

A headshot session, ecommerce product shoot, and event assignment have different inputs and delivery requirements. Start with one. For product photography, define the number of products, final images, backgrounds, file formats, and when the delivery clock begins.

If the client must ship products or approve a shot list, make those dependencies visible. “Delivery in seven days” is ambiguous unless everyone knows what starts the seven days.

| Package component | Example decision |
| --- | --- |
| Inputs | Products, brief, participants, or location access |
| Shoot | Agreed duration and shot list |
| Deliverables | Final edited image count and file specifications |
| Revisions | Included correction round and scope |
| Usage | Permitted use agreed in the contract |

## Make reservation payments part of the record

An illustrative $600 package with $150 paid to reserve the shoot leaves $450 toward the service price. If a separate location expense is later approved, record it as an agreed addition. The client should be able to reconcile the total from the quote and receipts.

## Distinguish revisions from a new assignment

Correcting an agreed edit is different from reshooting because the client changed packaging after the shoot. Define how each is handled. An unlimited-revision promise can turn a fixed-price package into an open-ended commitment.

If a $600 project occupies two hours shooting, four editing, and two in preparation and administration, it produces $75 gross per occupied hour before equipment, travel, fees, and other expenses. Tracking all eight hours provides a more useful pricing signal than dividing only by shoot time.

## Deliver files with the right context

Use a delivery method suitable for the file sizes, privacy needs, and proofing process. If you plan to use Whop’s Files app, verify its current behavior in your account before promising a particular client experience. Keep specialist galleries where they solve a real problem.

Clarify image usage through an appropriate agreement. Payment alone should not be treated as resolving every copyright or licensing question. Obtain permission before using client work in your portfolio and avoid publishing private project material in a shared space.

A focused pilot could be one product-photo package with one revision round and a clear delivery date.
