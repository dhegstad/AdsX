## Compare the source with the displayed frame

Record the original image dimensions, section, theme version and the desktop and mobile screenshots. Identify what must remain visible: the backpack's opening, a product detail or a person using the item. Keep that requirement more specific than make it look better.

Ask an image-capable assistant to describe the clipping and propose a review order. It should not invent hidden product details or recommend regenerating the merchandise just to fill an awkward frame. A crop problem is not automatically a reason to alter what the product looks like.

## Try the native layout controls first

Shopify explains that banners and slideshows can crop images to the section's shape. Depending on the theme, adjusting section height or using an image-adapted setting can help. A focal point identifies the important area, but support depends on the theme and version; third-party themes need their own documentation check. [Shopify image and focal-point guidance](https://help.shopify.com/en/manual/online-store/images/theme-images)

Test one change at a time in a theme preview. If adapting the section keeps the subject visible but makes the page excessively tall, record that tradeoff. If a focal point preserves the product while leaving the intended layout intact, it may meet the requirement without a new app.

There is one focal point per image, and Shopify applies it wherever that image is used. Review other placements before changing it. A point that favors the backpack in a narrow banner may affect a collection tile using the same asset.

## Crop a copy only when the layout needs it

When a separate composition is justified, preserve the original and identify where the new asset will be used. Shopify's media editor supports cropping; its instructions distinguish desktop saving from mobile saving, which creates a new copy. Verify the actual file and placements after the edit. [Shopify media editor](https://help.shopify.com/en/manual/shopify-admin/productivity-tools/media-editor)

For the fictional backpack, compare a landscape composition for the wide section and a tighter version for a supported mobile image setting. Do not promise every theme offers separate device images. If it does not, evaluate a different section or provider-supported customization before adding brittle CSS.

## Use a small visual acceptance set

Inspect a narrow phone, a wider phone and desktop. Check the important subject, any text overlay, button contrast and spacing. Review the other pages sharing the image. A focal point cannot guarantee that several distant details all remain visible inside every crop.

The decision is whether native settings meet the requirement, a new composition is needed, or the theme needs support. It is not a claim that an AI-generated replacement improves conversion.

For a hypothetical cost comparison, one hour of review at $40 costs $40. Avoiding a $5 monthly crop-only tool saves $60 over twelve payments before future review work. Use the actual app's price and full feature list before cancellation. No image or theme test was performed in a merchant store for this guide.

## Try the worksheet prompt

Illustrative prompt, not execution-tested.

> Review supplied source image dimensions, desktop/mobile screenshots, theme/version, section settings and required visible subject. Separate source composition from section cropping. Propose one native-setting or focal-point check at a time, with theme-support verification and all shared placements reviewed. Recommend a separate asset only with a stated need and original preserved. Do not invent product details, assume separate mobile-image support or claim conversion gains.
