To use Claude with an existing Shopify store, start in Claude on a desktop browser. Shopify provides an official connector. You sign in to Shopify to authorize it, then ask about your store from the connected conversation. If you only want copy suggestions for a single product, you can also paste its approved specifications into a chat without connecting the store.

## Connect an existing store

1. Open the installation link in [Shopify’s Claude connector guide](https://help.shopify.com/en/manual/ai-powered-tools/connecting-ai-tools/shopify-connector-for-claude) from a desktop browser. The install starts in Claude.
2. Follow the authorization step into Shopify. Check the store name, the signed-in account and the access Claude requests. For a reporting task, choose read access. Writing changes requires additional access and appropriate Shopify permissions.
3. Start with a lookup you can verify. Ask Claude to read the title and price of one known variant, including its currency. Compare the result with the same variant in your admin before using the connection for a larger task.
4. If the expected data is missing, check the store, account permissions and whether your Claude workspace allows the connector in that conversation. Shopify explains how to switch stores or revoke the connection in its [access guide](https://help.shopify.com/en/manual/ai-powered-tools/connecting-ai-tools/authorizing-access).

Shopify lists no additional connector fee. Your Shopify plan and any Claude subscription still apply. If you choose a separate automation service, check what it bills per run, including retries.

## Three first tasks for a connected merchant

These are illustrative prompts. AdsX has not run them against a merchant account.

**Product copy.** Suppose your enamel mug has a documented 350 ml capacity but no supplier guidance on dishwasher use. Ask: “Read the specifications for this mug. Draft a description under 70 words using only those facts. List unanswered care questions separately. Leave the product unchanged.” A useful draft can describe capacity. A claim that the mug is dishwasher-safe needs a source before publication.

**Customer support.** Give Claude a redacted question and the approved returns policy. Ask: “Draft a reply to a buyer who received the wrong size. Quote the policy passage supporting the next step. Flag any decision the support agent must make.” Staff can check the order and send the reply. Refunds and payment capture are handled outside the connector.

**Sales analysis.** Ask: “For the last complete calendar month, list my five highest-selling variants by units. Show the date range, timezone and how returns are treated. Flag any missing input.” Reconcile one variant against the same dates and metric in Shopify. A top seller by units can rank differently by net sales. For another analysis prompt, use the [merchant prompt library](/resources/shopify-merchant-prompt-library).

## When you need an automatic trigger

A connected conversation suits a request you initiate. For a workflow that starts whenever a product is added, [Zapier documents a Shopify new-product trigger paired with an Anthropic message](https://zapier.com/apps/anthropic-claude/integrations/shopify/255695105/send-messages-in-anthropic-claude-for-new-products-in-shopify). That template sends the product information to Claude. Decide where the resulting draft goes and who approves it before adding a publish step.

Try one draft product, then replay the same input. A review queue should recognize the same product ID and avoid creating a second pending change. For a batch edit, record which items completed and compare the saved fields before retrying. If you want to change your storefront layout, start with an unpublished theme and follow the [Claude Code and Shopify Liquid tutorial](/blog/claude-code-shopify-theme-liquid-build-guide).
